# Security reporting

Do not post API keys, bank tokens, financial records, recovery copies or private
backups in public issues. Use GitHub's private vulnerability reporting if the
repository owner has enabled it. Otherwise request a private reporting channel
without including exploit details or personal data.

See [consumer hardening](docs/CONSUMER_HARDENING.md) for the storage model,
verification performed and remaining release requirements. The current locked
Electron runtime needs an upgrade before a new release is distributed.
